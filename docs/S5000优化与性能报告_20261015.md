## 最新结果与口径

21个正式PDB，每个输入5个结构；10 cycles、200 diffusion steps、seed101，BF16，use_msa=True，diffusion shared-vars cache、efficient fusion、TF32均开启。每个PDB先完整warm一次，再正式执行一次；正式轮数为1。

| 指标 | A100 | S5000融合版 |
|---|---:|---:|
| 正式样本日志累计 | **421.24秒** | **468.35秒** |
| 相对A100吞吐 | 100% | **89.94%** |
| Job循环扣除warm | 未取得同边界结果 | **494.49秒** |

吞吐比=421.24/468.35=89.94%，S5000比A100低10.06%。不是逐PDB百分比的平均值。

- 日志累计：只取21条正式名字的 `Model forward time`，包含predict、后处理和写盘，排除取batch之前的特征准备。
- 扣warm的Job：1004.66秒减去510.173974秒warm迭代窗口，得到494.49秒；还包含正式数据等待、准备和公共循环开销。
- 两项都不包含warm，也都不包含模型启动/加载；494.49秒不是从命令启动到进程退出的总墙钟时间。
- **A100的421.24秒对应S5000的468.35秒，不能与494.49秒直接比较。**

## 当前实际方案，已合并替代关系

| 方案 | 当前实现 |
|---|---|
| 主干TriangleAttention | MUSA Flash |
| TriangleMultiplication | 当前输出融合实现，包含乘法及输出处理；旧融合路径不另计一项收益 |
| Triangle Q/K/V/gate | 输入投影合并 |
| Diffusion静态pair缓存 | 缓存归一化及bias |
| 多样本diffusion条件共享 | 相同噪声条件下共享conditioning |
| Confidence乘法 | BF16 Mutlass |
| 普通LayerNorm | fast LayerNorm；已有融合kernel中的归一化保持原实现 |
| 标准/局部attention | BF16 SDPA，局部5维布局展平为4维后使用SDPA |
| Diffusion Q/K/V/gate | diffusion模块内的投影合并，与Triangle模块不同 |
| Transition | SwiGLU融合 |
| AdaLN | scale/shift投影合并 |
| Confidence attention | BF16＋v21，主干仍走Flash |

七个新增开关是 `fast_ln, sdpa, local, qkvg, swiglu, adaln, confv21`；其中SDPA和局部展平按一个配套方案列示。未启用显式BF16 pair bias及CF布局候选。历史不分块开关在本组最多964 tokens时调用0次，未列入有效方案清单。

## 单PDB筛选，不能外推为完整任务收益

7rev，851 tokens，N_sample=1，10 cycles、200 steps。每项先做1 cycle＋2 step短预热，模型与特征各准备一次，计时仅为同步后的predict调用，排除后处理和写盘。首尾基准42.462/42.286秒，均值42.374秒。

|---|---:|---:|---|
| fast LayerNorm | 39.229 | +8.02% | 启用 |
| 标准 attention BF16/FP32→BF16 SDPA | 40.632 | +4.29% | 启用 |
| 标准 SDPA + 局部 attention 展平 | 40.679 | +4.17% | 启用 |
| Diffusion Q/K/V/gate 合并投影 | 42.148 | +0.54% | 启用 |
| Transition SwiGLU 融合 | 41.279 | +2.65% | 启用 |
| AdaLN scale/shift 投影合并 | 42.200 | +0.41% | 启用 |
| Confidence BF16 + v21 attention | 41.300 | +2.60% | 启用 |
| 已有 pair bias 缓存显式 BF16 | 42.683 | -0.72% | 未启用 |
| TriangleMultiplication CF 布局 LN/gate | 42.657 | -0.66% | 未启用 |
| 以上新增项全部组合 | 34.370 | +23.29% | 全部九开关筛选，不是当前七开关组合 |

23.29%来自全部九个开关，含两个单项负收益候选；不是当前七个正收益开关的21PDB收益。SDPA与SDPA＋局部展平是依赖组合，不能相加。AdaLN与Diffusion QKVG的微小正变化约0.4%～0.54%，尚未证明统计稳定性。

此前385.85秒基准使用N_sample=1，不能与本次N_sample=5直接计算增量。当前没有旧版同口径五采样配对结果，**尚不能宣称本轮七个新增开关使完整21PDB提升了某个百分比**。
