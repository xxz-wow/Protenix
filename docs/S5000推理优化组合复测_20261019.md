# S5000推理优化组合复测

当前发布18项：原15项＋局部Attention展平＋AdaLN合并投影＋源mask检查优化。模型函数逐字节对应已完成复测的源码；没有新增适配器。

## 统一口径

21PDB、protenix_base_default_v0.5.0、BF16、10 cycles、200 steps、5 samples、seed101；预计算MSA/cache/efficient fusion/TF32开启。每PDB完整warm一次后正式一次，仅一轮。累计正式Featurizing→succeeded，包含特征处理、预测、后处理、写盘，排除所有warm、启动加载及succeeded之后清理。

| 配置 | 正式完整流程 | 日志Model forward time累计 |
|---|---:|---:|
| 原15项 | 429.346秒 | 404.14秒 |
| 原15项仅加mask优化 | 420.160秒 | 394.76秒 |
| 当前18项 | 409.691秒 | 384.22秒 |
| 飞书参考 | 408.665秒 | 383.88秒 |

当前组合相对原15项吞吐提升4.80%，节省19.655秒；mask隔离对照提升2.19%，节省9.186秒；在15项＋mask上恢复16、17联合提升2.56%，节省10.469秒。各项百分比不能相加，16、17未分别拆测。

当前组合相对飞书参考耗时多1.026秒，吞吐比例99.75%。自有三次使用同一物理GPU，参考为另一张同型号GPU；不同时间、单轮结果，不能保证小幅差异稳定。

Job循环扣warm分别为429.486、420.295、409.827秒，是包含少量尾部清理的另一口径，不与上表混算。日志Model forward time包含其计时区间内的预测、后处理和写盘，不是纯GPU前向。

## 实现与命中

局部展平依赖BF16 SDPA，单独关闭依赖时不触发；AdaLN历史全关基线单项-0.11%不代表在局部BF16全开组合中无用。保留两项以本次联合对照为依据，不为单项编造收益。

当前组合计数含warm：local_flatten 50400、adaln 403200、mask_none_fastpath 47040。源mask均为None，直接使用已知全一结果；非空mask缓存命中和未命中均0。将判断传入下层，消除对新建mask bias的反复GPU归约和.item()。共享助手使用弱引用和版本签名验证非空mask缓存有效性。

## 输出与精度边界

两轮本日新实验各有21个正式样本、105个正式结构，含warm210个结构。样本数、原子数、坐标有限性和与历史输入shape一致性通过，未完成结构准确率验收。

仅mask版与原15项的105份CIF均非逐坐标相同；按原子顺序Kabsch对齐RMSD中位数0.315319 Å、最大13.526403 Å。未做同源链置换匹配，也未做同版本重复运行波动对照，不能把差异直接归因于mask或宣称精度等价/退化。当前18项同样不宣称结构精度等价。
